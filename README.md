# Мини-Ферма: Сбор и защита урожая

Учебный проект по курсу **«Проектирование и разработка игровых приложений»** (Практика №1 / Домашняя работа №1: Gray-box Prototype).

Стек: **TypeScript + Phaser + Vite + GitHub Pages**.

---

## 1. Что это за игра?

**«Мини-Ферма: Сбор и защита»** — это аркадный микроменеджмент фермерского участка.
Игрок управляет фермером, который ухаживает за грядками: сажает семена, носит воду из колодца для ускорения полива, отпугивает наглых ворон и собирает спелый урожай моркови, чтобы выполнить дневную норму выручки.

- **Формула игры:** Игрок сажает, поливает и собирает урожай, чтобы заработать 100 монет за смену (90 сек), пока наглые вороны пытаются склевать созревшие овощи.
- **Длительность партии:** 1–2 минуты осмысленного, динамичного игрового процесса.

---

## 2. Как управлять?

- **Перемещение фермера:** Клавиши со стрелками или `W`, `A`, `S`, `D`.
- **Действие:** `ПРОБЕЛ`, `E`, `Enter` или **клик мыши / тап**:
  - у пустой грядки — посадить семена;
  - у сухой грядки — полить грядку (`-1 💧` из лейки);
  - у колодца — наполнить лейку водой до максимума (`3/3 💧`);
  - у созревшей грядки — собрать урожай (`+10 🪙`);
  - у грядки с вороной — **спугнуть ворону**, пока она не съела овощ;
  - у увядшей грядки — расчистить землю.
- **Начать заново:** Клавиша `R` или кнопка **🔄 Заново (R)** в верхнем правом углу.
- **Звук:** Кнопка **🔊 Звук / 🔇 Выкл** в правом верхнем углу (процедурный Web Audio синтез).

---

## 3. Что должен делать игрок? Цель и препятствия

1. **Цель игры (Победа):** Заработать **100 монет** (10 собранных грядок) до окончания смены.
2. **Ограничение по времени:** Таймер смены длится **90 секунд**. Если время вышло, а квота не набрана — поражение.
3. **Опасность (Вороны и лимит потерь):**
   - Через некоторое время после созревания на грядку может прилететь ворона (`🦅`).
   - У игрока есть **6 секунд**, чтобы подбежать и прогнать её.
   - Если не успеть, урожай уничтожается, а счётчик потерь увеличивается (`⚠️ Потери: X / 3`).
   - Если фермер допустит **3 потери** — наступает поражение («Ферма разорена»).
4. **Ресурс воды:**
   - Полив ускоряет рост моркови почти в 3 раза (с 13 до 4.5 секунд).
   - Лейка вмещает 3 заряда. Игроку необходимо планировать маршрут и регулярно бегать к колодцу слева.

---

## 4. Что пока не реализовано (планы на следующие этапы)

- Разные виды культур (пшеница, томаты, тыквы с разным временем роста и стоимостью).
- Магазин улучшений (увеличение вместимости лейки, ускорение бега, пугало от птиц).
- Смена дня и ночи, погодные эффекты (дождь, автоматически поливающий все грядки).
- Кастомный пиксель-арт спрайтсет вместо примитивов.

## 5. Запуск и сборка

### Локальный запуск:
```bash
npm install
npm run dev
```
После этого открыть адрес в браузере (обычно `http://localhost:5173/`).

### Проверка типов и production сборка:
```bash
npm run typecheck
npm run build
```

### Предпросмотр собранной версии:
```bash
npm run preview
```

### Публикация на GitHub Pages:
В репозитории настроен GitHub Actions workflow `.github/workflows/deploy.yml`. Достаточно запушить код в свой репозиторий на GitHub и в настройках репозитория (**Settings → Pages**) выбрать **Source: GitHub Actions**.
