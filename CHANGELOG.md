# CHANGELOG

Короткий журнал работы над проектом.

## Практика / домашняя работа №1

**Что сделал:**

- Спроектировал и реализовал прототип «Мини-Ферма: Сбор и защита урожая» на Phaser + TypeScript.
- Создал игровое поле с 6 грядками с полным циклом: посадка, полив, созревание, сбор, увядание и расчистка.
- Добавил колодец и механику расхода воды из лейки (запас на 3 полива).
- Реализовал препятствие и риск: набеги ворон на созревший урожай с таймером спасения 6 секунд и лимитом в 3 потери.
- Добавил понятный HUD: цель 100 монет, обратный отсчёт смены 90 секунд, индикаторы ресурсов и всплывающие подсказки прямо над персонажем.
- Реализовал процедурные звуки действий через Web Audio API с кнопкой включения/выключения звука.
- Добавил условия победы, поражения и перезапуск игры кнопкой и клавишей `R`.

**Что пришлось убрать или упростить:**

- Отказался от множества типов культур и сложного инвентаря в пользу одного сбалансированного овоща (моркови) для чистоты кор-геймплея.
- Использовал визуальный стиль gray-box прототипа (геометрические фигуры + иконки-эмодзи) вместо рисованных ассетов, чтобы уложиться в лимит времени.

**Что оказалось сложнее, чем ожидалось:**

- Балансировка соотношения скорости роста растений (4.5с при поливе vs 13с без полива) и частоты атак ворон для комфортной игры на 1.5–2 минуты.
- Корректная инициализация Web Audio контекста по пользовательскому жесту без предупреждений консоли браузера.

**Где использовал AI и для чего:**

- Для проектирования игрового баланса, написания кода сцены `GameScene.ts` по строгим стандартам TypeScript и оформления отчётных файлов курса.
